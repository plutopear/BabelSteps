# Security policy

BabelSteps records screens and keystrokes, so security and privacy bugs matter more than most.

## Reporting a problem

Please report security or privacy problems privately, not in a public issue:
use **Security > Report a vulnerability** on the GitHub repository page.

Useful to include: what you did, what you expected, what happened, and the BabelSteps version and Windows version. Do not attach real recordings or screenshots that show private information.

## What counts

- Anything that sends data off the machine. The app is designed to make no network connections at all.
- Passwords or typed text saved when they should have been dropped.
- Sensitive content left in an export after redaction, or in image or PDF metadata.

See `docs/04-privacy-and-security.md` for the promises and the automatic checks.
